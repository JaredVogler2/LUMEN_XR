# 04 — CAD assembly, verification, exports and print preparation

Build models using FreeCAD native geometry, parameter spreadsheet or explicit JSON-driven script. Keep generation deterministic and editable; no proprietary cloud dependencies. Use named dimensions and source-controlled configuration. Prefer individual parts + full assembly with transforms and explicit joints. Maintain cad/src, cad/native, cad/step, cad/stl, cad/3mf (if supported), cad/preview, tests, docs and print_profiles. Generate manifest of file names, revision, units, bounding boxes and SHA256. Produce each printable part as one valid watertight mesh, STL in mm; export editable FCStd and STEP for solids, no STEP export from triangulated STL masquerading as original CAD. Assembly model for inspection only, do not slice assembly as a fused part. Mesh resolution choose based on mating tolerances, document chord error. Generate source with instructions and optional OpenSCAD fallback where practical. Never fabricate artifact paths. Use CAD validity checks, solid count/volume/bounds, nonmanifold/self-intersection checks with suitable local tool; check expected clearance/interferences, note intended contacts. Verify all configs 4 widths x 3 heights (including 25.4x12.7 and 254x152.4), both loading/release states, phone keep-outs and print orientations. Render front/back/side/isometric, exploded view, close-up of pass-through lock and retaining lip, min/max extension. Visually inspect results and fix; screenshots not substitutes for geometry checks. Calculate angular deflection from rail/jaw play; estimate load with assumed mock forces and clearly label, no FEA claim unless actually run with documented boundary conditions.

Printer unknown: default planning envelope 220x220x250 mm, 0.4 nozzle, 0.2 layer as provisional. Design modular pieces or stock rails for >220 mm; check actual oriented bounding box including brim/support. Suggested PETG for mock prototypes; initial 4 perimeters and 25–40% infill as hypotheses, tune per geometry. Snap clip print along favorable layer direction, radius at root. Test coupons: guide fits 0.15/0.25/0.35/0.45 mm per side, phone latch fit, label slot widths and release, rail joint stiffness and pad retention. Print coupons first, measure with caliper and adjust params. Avoid unsupported long bridging and trapped supports. Provide part orientations, support locations, print quantity, infill/filament guidance, estimated mass/time only if actual slicer reports; otherwise mark unknown. Document BOM (printed parts, stock rails, fasteners, pads), dimensions and alternatives, no invented supplier quote. Add slicer-compatible 3MF project only if actual printer profile is supplied or explicitly generic. Do not emit or send printer-specific G-code until owner supplies printer model, nozzle, firmware and material; inspect slicer preview and require human approval. Do not connect to printer or start print. Produce STL manifest and step-by-step assembly drawings. Mark unrun checks NOT RUN.

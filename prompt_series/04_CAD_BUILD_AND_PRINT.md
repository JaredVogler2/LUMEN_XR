# 04 — CAD assembly, verification, exports and print preparation

Build models using FreeCAD native geometry, parameter spreadsheet or explicit JSON-driven script. Keep generation deterministic and editable; no proprietary cloud dependencies. Use named dimensions and source-controlled configuration. Prefer individual parts + full assembly with transforms and explicit joints. Maintain cad/src, cad/native, cad/step, cad/stl, cad/3mf (if supported), cad/preview, tests, docs and print_profiles. Generate manifest of file names, revision, units, bounding boxes and SHA256. Produce each printable part as one valid watertight mesh, STL in mm; export editable FCStd and STEP for solids, no STEP export from triangulated STL masquerading as original CAD. Assembly model for inspection only, do not slice assembly as a fused part. Mesh resolution choose based on mating tolerances, document chord error. Generate source with instructions and optional OpenSCAD fallback where practical. Never fabricate artifact paths. Use CAD validity checks, solid count/volume/bounds, nonmanifold/self-intersection checks with suitable local tool; check expected clearance/interferences, note intended contacts. Verify all configs 4 widths x 3 heights (including 25.4x12.7 and 254x152.4), both loading/release states, phone keep-outs and print orientations. Verify both side lips are 50.8 mm high in every configuration, short-label finger access, tall-label overhang (up to 101.6 mm), and clearance during loading and release. Include 0.5-inch and 6-inch-high labels in physical coupon trials; do not claim their retention is proven from CAD alone. Render front/back/side/isometric, exploded view, close-up of pass-through lock and retaining lip, min/max extension. Visually inspect results and fix; screenshots not substitutes for geometry checks. Calculate angular deflection from rail/jaw play; estimate load with assumed mock forces and clearly label, no FEA claim unless actually run with documented boundary conditions.

Printer unknown: default planning envelope 220x220x250 mm, 0.4 nozzle, 0.2 layer as provisional. Design modular pieces or stock rails for >220 mm; check actual oriented bounding box including brim/support. Suggested PETG for mock prototypes; initial 4 perimeters and 25–40% infill as hypotheses, tune per geometry. Snap clip print along favorable layer direction, radius at root. Test coupons: guide fits 0.15/0.25/0.35/0.45 mm per side, phone latch fit, label slot widths and release, rail joint stiffness and pad retention. Print coupons first, measure with caliper and adjust params. Avoid unsupported long bridging and trapped supports. Provide part orientations, support locations, print quantity, infill/filament guidance, estimated mass/time only if actual slicer reports; otherwise mark unknown. Document BOM (printed parts, stock rails, fasteners, pads), dimensions and alternatives, no invented supplier quote. Add slicer-compatible 3MF project only if actual printer profile is supplied or explicitly generic. Do not emit or send printer-specific G-code until owner supplies printer model, nozzle, firmware and material; inspect slicer preview and require human approval. Do not connect to printer or start print. Produce STL manifest and step-by-step assembly drawings. Mark unrun checks NOT RUN.

## Saddle-specific validation
Export top-edge saddle, moving jaw, captive keeper, case insert variants, datum/fit coupon and dummy phone independently. Model and check bare/rounded/rimmed generic phone envelopes and case thickness extremes; show front/back jaw travel, seating datum contact, stop engagement, camera and screen keep-outs, panel standoff and assembly/removal path. Physically validate before full build; report measured fit and repeatability, not universal compatibility from CAD. Check max rail extension torque and case compression. Preserve 50.8 mm fixed side lips.


## C-clip deliverables and verification
Generate separate editable CAD and printable coupons for compliant C-clip variants, rigid datum bridge and optional captive keeper. Include cross-sections showing relaxed, thin-case and thick-case conditions, contact/keep-out regions, root fillets and overtravel stops. Assess clip loading and print anisotropy; do not claim FEA or fatigue results unless executed. Document material, orientation, gap matrix, measured force/fit and repeated reseating angular error, including maximum rail torque. Confirm the rigid reference remains independent of flexure. Retain adjustable jaw as fallback. No printer-specific G-code until printer is identified.

# 01 — Requirements, CAD environment and design trade study

Act as lead mechanical engineer and CAD automation agent. Read README and all prompts first. Inspect repository and available local tools (FreeCAD version, Python environment, MCP tools, slicer CLI, OS, git). Prefer native FreeCAD Python macro/Part Design or equivalent parametric solids, optionally use reviewed MCP to drive it. If MCP is unavailable generate and run local scripts; if CAD cannot execute, produce source and explicitly mark unbuilt outputs. Record versions and reproducible commands. Use millimeters internally (25.4 mm/in). Create docs/requirements.md, docs/decisions.md, config/parameters.json and a traceability matrix. Never ask for known placard dimensions; continue with a provisional phone envelope and ask owner to measure before final cradle.

Design inputs: rectangular flexible adhesive labels width 25.4–254, height 12.7–152.4 mm, orientation portrait iPhone underneath, open-top insertion, face toward mechanic, adhesive toward mock wall, gravity seat at bottom. Two-handed operation without needing to hold a separate phone, with one hand stabilizing fixture while other applies or activates release. Side guides must pass through housing like a bar clamp, not require nested expansion or complete disassembly. Top and central front/back remain open. Both vertical side guide lips are fixed at 50.8 mm (2 inches) above the lower seating datum regardless of label height. Width is adjustable; vertical telescoping guides are out of baseline scope. Short labels remain within the guides; taller labels protrude above. Verify short-label finger access and tall flexible label stability and quantify limitations. Support label thickness and liner thickness as independent measured parameters; initial coupon sweep 0.10/0.25/0.50/1.0 mm total thickness is exploratory, not a specification. No adhesive-contacting permanent lips. Flat target area; curved origin measured using low-tack ruler tape conforming to surface. No need to reconstruct J curve mechanically.

Define axes X along placard width, Y up, Z toward panel; tool reference plane is contact-pad plane; phone portrait short axis nominally X, long axis Y. Set fixed lower-left placard datum as mechanical anchor, top-left pointer derived from label height; record geometry of all offsets and calibrate actual orientation. Compare fixed-left + movable right vs symmetric jaws; dual bar vs keyed single extrusion; printed vs standard metal/polymer rods; segmented vs continuous rails; spring vs cam vs manual slider release; mechanical retention with liner vs front-face tabs vs low-vacuum suction as fallback. Score stiffness, angular backlash, FOD, printability, weight, small label handling, overhang at maximum extension, reach, panel damage, release reliability, phone fit and cost. Choose based on tests, not aesthetics; creativity permitted. Baseline: fixed-left/movable-right, captive anti-rotation guides, open top, nonmarring standoff, positive phone lock. Do not force this if another concept tests better. Define design targets as hypotheses: angular play <=0.1° allocation only if supported; prototype repeatability <=0.25° provisional, not engineering acceptance. 10-inch width converts 0.1° to ~0.44 mm endpoint height difference. Identify load paths and build failure mode table; no claims of certified tooling. No employer-specific data in public repo.

Before advancing: output sketches/orthographic diagrams, chosen concept and reasons, parameter list, and exact missing phone/printer data. Measure phone with case installed: overall W/H/T, corner radii, camera bump location/protrusion, button envelopes, speaker/port clearance, case compliance. Add printable gauge coupon. Provisional dummy phone must be clearly labeled; do not assert universal snap fit. Ask for printer build volume/nozzle only before final slicing, not design. Record generic 220x220 mm bed as provisional planning constraint.

## Start here
Run the prompts in `prompt_series/` in numerical order using a coding agent with local shell access (Claude Code or Kiro) and optionally a FreeCAD MCP bridge. The goal is real, editable CAD and individually printable parts, not just images, meshes invented without validation, or design descriptions. This is a generic mock-panel prototype, not approved aircraft tooling. This public repository must never contain employer data, drawings, photos, credentials, part numbers, internal specifications or actual aircraft geometry.

## Master prompt to paste into the agent
Read this README and every file in prompt_series before designing. You are a mechanical fixture design engineer, computational CAD engineer and FDM manufacturing specialist. Build a portrait-iPhone-mounted, open-top, adjustable perimeter applicator for flexible rectangular adhesive labels 25.4–254 mm wide and 12.7–152.4 mm high. The phone is below the placard, display facing mechanic, rear facing wall. Gravity seats placard onto a lower datum rail. Both faces and top are open; side/bottom retention must withdraw before bonding without lifting the label. A fixed left anchor and movable right jaw with captive pass-through rails (like a woodworking bar clamp) are the preferred architecture, not a telescoping enclosure. Both vertical guide lips have a standard fixed height of 50.8 mm (2 inches) measured from the bottom seating datum. Only horizontal width is mechanically adjustable in the baseline. Shorter labels sit within the guides; taller labels extend above them. Do not add telescoping vertical guides or a top crossbar. Validate tall flexible labels; optional auxiliary face support only if testing demonstrates need. Provide a positive-lock, non-marring portrait phone cradle, button/camera/port clearance, a reference edge for floor tare, a calibrated relationship between phone sensor axis and the placard datum, a visible top-left targeting index, and removable liner/application sequence. Explore alternatives and choose based on engineering evidence; document every deviation. Support full specified size range or identify explicit validated limitations. Use mock panels only. Produce parametric models, assembly, build scripts, part-level exports, illustrations, test coupons, BOM, assembly instructions, calibration and validation protocols. Run CAD tools, inspect renders, check solids and interference, export files, and commit generated outputs to this repository. Do not fabricate successful runs, print results, accuracy, or safety approvals. Do not send G-code to a printer or order parts without approval. Do not wait for unknown exact phone/printer data: use clearly labeled example dimensions, keep parameters editable and mark the final phone cradle and slicing profile blocked until measured. Do not treat personal cloud services as approved work systems.

## Mechanical refinement — universal top-edge mount
Prefer a compact removable portrait-phone top-edge saddle rather than a full-length model-specific cradle. Seat the structural rail directly above and nominally parallel to the phone/case top edge, with a rigid two-point datum and adjustable front/back jaw spacing for cases. Maintain positive mechanical retention, button/screen/camera keep-outs, independent panel-contact pads and measured angular calibration. See prompt 02 for detailed requirements. The fit range is provisional until measured.


## Preferred V1 phone attachment — compliant C-clip
Use a printed resilient C-shaped top-edge clip (cross-section in the phone thickness direction, open downward) with a rigid, repeatable two-land top datum and rounded compliant arms. Prefer this passive snap-on concept over a screw or cam for the first mock prototype if measured retention and angular repeatability are adequate. Do not force one clip to cover the full provisional 8–20 mm case-on thickness range; print interchangeable calibrated clip sizes as necessary. Preserve positive retention on suitable case features, camera/button/glass clearance, and independent panel-contact standoffs. See prompt 02. This refinement supersedes the earlier preference for a screw-operated jaw, not the safety and calibration requirements.

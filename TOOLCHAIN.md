# Free CAD, agent and slicer workflow

Recommended: FreeCAD (https://www.freecad.org/downloads.php) + Claude Code or Kiro local shell. Optional third-party MCP bridge: https://github.com/neka-nat/freecad-mcp ; inspect current README, license, permissions, pin a reviewed revision and install per instructions. It uses a running FreeCAD instance with RPC addon and a local stdio MCP server. Verify actual tool registration before modeling; don't invent MCP names. Review arbitrary Python execution risks. Bind RPC to loopback only, personal synthetic-data environment; never expose it publicly or put tokens into repo. Start with simplest workflow: agent generates FreeCAD Python scripts/macros and runs locally, inspects output. MCP is optional, not a requirement for CAD automation. Alternate: OpenSCAD (https://openscad.org/downloads.html), agent writes parametric .scad then runs openscad -o part.stl part.scad; great for simple solids but prefer FreeCAD for native editable/STEP. Reference https://files.openscad.org/documentation/manual/Using_OpenSCAD_in_a_command_line_environment.html .

Kiro IDE: workspace .kiro/settings/mcp.json, local stdio command/args taken verbatim from bridge README, absolute path if needed. Official https://kiro.dev/docs/mcp/configuration/ . Claude Code: claude mcp add --transport stdio freecad -- <reviewed-command> <args> ; confirm with claude mcp list; documentation https://code.claude.com/docs/en/mcp . Exact bridge setup OS-dependent. Ordinary ChatGPT chat cannot directly run desktop localhost MCP; can generate scripts or files and use GitHub connector, but use local coding agent for reliable GUI execution. For any remote MCP use approved secured configuration, not public CAD RPC. Clone repository, paste master prompt, let agent build and inspect, git add/commit/push generated files. Do not blindly approve arbitrary third-party commands.

Slicing: separate from modeling. PrusaSlicer https://www.prusa3d.com/page/prusaslicer_424/ ; OrcaSlicer https://github.com/OrcaSlicer/OrcaSlicer/releases ; Bambu Studio https://bambulab.com/en/download/studio ; Cura https://ultimaker.com/software/ultimaker-cura/ . Select official supported printer profile: Bambu -> Bambu Studio or compatible Orca; Prusa -> PrusaSlicer; Creality/Ender/other -> vendor-supported Orca/Cura or official slicer; verify model. Import part STL or 3MF, set units mm, choose material/nozzle/bed, orientation, supports, infill, preview every layer and check build envelope, then export G-code or use supported network send/SD/USB. G-code is printer and material specific; never send generic G-code. Printer model, nozzle, firmware and build volume required to finalize; no auto-print. Save source CAD and STEP/STL to GitHub, and optional printer-specific project profiles labeled with revision; do not commit secrets or machine credentials.
